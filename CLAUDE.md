## Application Building Context

Read the following files in order before implementing or making any architectural decision:

1. `context/project-overview.md` — project definition, goals, features, and scope
2. `context/architecture.md` — system structure, boundaries, and database model
3. `context/ui-context.md` — theme, colors, typography, design, and component conventions
4. `context/code-standards.md` — implementation rules and conventions
6. `context/progress-tracker.md` — current phase, completed work, open questions, and next steps

Update `context/progress-tracker.md` after each meaningful implementation change.

If implementation changes the architecture, scope, or standards documented in the context files, update the relevant file before continuing. Ask for permission before updating.
